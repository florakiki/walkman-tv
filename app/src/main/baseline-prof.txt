# Baseline Profile（第二十六轮，手写）
# 冷启动类加载是首帧慢的最大头（1–3 秒，无 Profile 时解释执行）。这份手写
# Profile 列出启动路径上的类，AGP 会把它打进 APK 的 assets/dexopt/baseline.prof，
# 系统在安装后预编译这些类，第二次启动起冷启动变快。
# 注意：侧载包没有 Play 的云端编译，profileinstaller 在首次启动后后台编译，
# 好处从第二次启动开始体现。类名写错了会被系统忽略，不影响启动。
# 格式：一行一个类，L<包路径>/<类名>;。Composable 函数写在它所在文件的 Kt 类里
# （如 TracksDetailOverlay.kt → TracksDetailOverlayKt）。
